# Ai Craft Suite

Role: Act as an expert full-stack developer and AI integration specialist.

Objective: Build a web application called AI Productivity that combines three AI-powered tools into one platform.

Context: The application helps users save time, improve productivity, and manage daily work efficiently.

Requirements:

Smart Email Generator: Create professional emails based on topic, purpose, and tone.

Meeting Notes Summarizer: Summarize notes and extract key points, decisions, and action items.

AI Task Planner: Create, prioritize, organize, and schedule tasks.

Integrate all three tools into one dashboard, allowing meeting action items to become tasks and meeting summaries to generate follow-up emails.

Provide a modern, responsive, secure, and user-friendly interface.

Output: Deliver a functional, AI-powered web application with an integrated dashboard, data storage, and mobile-friendly design that simplifies email writing, meeting management, and task planning.
